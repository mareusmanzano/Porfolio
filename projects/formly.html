Overview

Formly is a small TypeScript library for validating form input without pulling in a large dependency tree. It ships at under 3KB gzipped.

The problem

Most form validation libraries I reached for on small projects felt oversized for what I actually needed, and their error messages were often too generic to show directly to users.

What I built

I designed a chainable, readable validation API (`field('email').required().isEmail()`) with error messages you can actually put in a UI, plus full TypeScript types so mistakes get caught at compile time.

  • Zero runtime dependencies, under 3KB gzipped
  • Fully typed, chainable validation rules
  • Human-readable, customizable error messages
  • Framework-agnostic — works with React, Vue, or plain JS

What I learned

Maintaining an open-source library taught me a lot about API design under real constraints — once people depend on your interface, every change has to be backward compatible or clearly versioned.
