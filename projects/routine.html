Overview

Routine is a habit-tracking app for people who find most habit apps too noisy. Instead of badges, points, and leaderboards, it focuses on a single clean streak view and a short weekly reflection.

The problem

Most habit trackers lean heavily on gamification — streak-breaking anxiety, pop-up rewards, and constant notifications. I wanted something that felt more like a quiet journal than a game, while still giving useful structure and feedback.

What I built

I built a React front end with a single-page daily view, a Node.js/Express API, and PostgreSQL for storage. Habits can be marked done with one tap, and a lightweight weekly summary email (built with a cron job) recaps the week without demanding daily engagement.

  • One-tap daily check-ins with optimistic UI updates
  • Streaks that soften rather than reset after a missed day
  • Weekly email digest generated server-side
  • Fully keyboard-accessible daily view

What I learned

This was my first project designing against gamification patterns on purpose. It taught me a lot about writing UI copy that reduces pressure instead of adding it, and about structuring a Node API around a single, very frequent write operation efficiently.
