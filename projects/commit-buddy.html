Overview

Commit Buddy is a small CLI tool that reads your staged git diff and suggests a clear, conventional-commit-style message — so you spend less time staring at the commit prompt.

The problem

Writing good commit messages is easy to skip when you're mid-flow, and 'wip' commits pile up fast. I wanted a fast, local tool that nudges toward better git hygiene without getting in the way.

What I built

Built as a Node.js CLI, it reads the staged diff via `git diff --cached`, sends a trimmed summary to the OpenAI API, and prints 2–3 suggested commit messages you can accept, edit, or discard entirely.

  • Reads staged diffs directly from git, no extra setup
  • Suggests messages following conventional commit format
  • Fully optional — never commits without explicit confirmation
  • Configurable message style via a local config file

What I learned

This project was a good, small exercise in designing a tool that assists rather than automates — every suggestion is a proposal the developer has to actively accept.
